# 网页快开

在 MioKit 搜索框里打开网页：搜索本机浏览器收藏夹，或用自定义网站、搜索模板直接跳转。

支持 **Microsoft Edge**、**Google Chrome**、**Mozilla Firefox** 的本地收藏夹；打开网页时可指定默认浏览器。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 自定义网站 | 固定网页按名称、别名或网址出现在全局搜索中；搜索模板用 `{query}` 把关键词填进 URL |
| 浏览器收藏夹 | 用命令附着搜索框后，按收藏夹标题查找并打开 |
| 默认浏览器 | 选择 Edge / Chrome / Firefox，或使用系统默认浏览器 |
| 快捷操作 | 网站可设别名、全局热键；可固定到首页，或从搜索中忽略 |

在搜索框输入 **网页快开** 并回车，即可打开管理窗口。

## 自定义网站

自定义网站始终参与全局搜索，不需要先输入命令。在管理窗口的「网站入口」页新增或编辑。

地址必须以 `http://` 或 `https://` 开头。

### 固定网页

填写一个完整网址，例如 `https://github.com`。

- 按网站**名称**、**别名**匹配（不匹配描述或网址）。
- 回车后直接打开该页面，不读取搜索框或剪贴板内容。

适合常用控制台、文档站、内部系统入口。

### 搜索模板

在地址中加入 `{query}`，例如：

```text
https://www.bing.com/search?q={query}
```

执行时会把 `{query}` 替换为 URL 编码后的查询内容。只要搜索框有输入，每个未忽略的搜索模板都会贡献一条结果，标题形如「使用 Bing 搜索“关键词”」，并排在结果列表靠后的位置。

查询来源可按网站单独设置：

| 查询来源 | 行为 |
| --- | --- |
| 输入优先，空时使用剪贴板 | 搜索框有内容时用输入；输入为空时用剪贴板（默认） |
| 仅使用输入 | 只用搜索框里的文字 |
| 仅使用剪贴板 | 只用当前剪贴板文字 |

热键触发搜索模板时，始终使用剪贴板文字替换 `{query}`，与上面的查询来源无关。

### 网站图标

保存网站后会自动获取并缓存站点图标。编辑时也可手动「获取图标」或「重新获取」。图标尚未就绪时，搜索结果先显示通用图标，就绪后自动更新。

## 浏览器收藏夹

收藏夹不参与普通全局搜索，需要先附着到搜索框。

### 怎么搜

任选一种方式：

1. 输入命令 `bookmark-web` 或 `favorites-web`，再按宿主配置的命令触发键。
2. 在搜索框输入 `/`，找到 **浏览器收藏夹** 并选中。

附着后按**收藏夹标题**包含匹配（不区分大小写），最多返回 50 条。结果会显示网址、浏览器、Profile 和文件夹。

### 索引从哪来

插件会读取本机已安装浏览器的本地数据：

- Edge、Chrome 的用户目录
- Firefox 的 Profile（含 `places.sqlite`）

启动时同步一次，之后每 5 分钟自动同步；也可在管理窗口「浏览器数据」页点「立即同步」。同步只建立可重建的本地索引，不会改写浏览器里的收藏夹。

任一浏览器 Profile 读取或解析失败时，会保留上次完整索引，并在「浏览器数据」页显示失败原因；下次同步成功后再更新索引。

停用或卸载插件时，会取消并等待 favicon 刷新与预取任务结束，之后再释放网络资源。

## 打开方式

在管理窗口「浏览器数据」页选择默认打开浏览器：

- 系统默认浏览器
- Microsoft Edge
- Google Chrome
- Mozilla Firefox

指定的浏览器不可用或启动失败时，自动回退到系统默认浏览器。仅打开 `http` / `https` 地址。

## 搜索结果操作

在自定义网站的搜索结果上按 `Alt`，可以：

- **固定 / 取消固定**：固定到搜索首页
- **别名**：用更短的名字命中该网站
- **热键**：绑定全局快捷键；固定网页直接打开，搜索模板用剪贴板填充 `{query}`
- **忽略搜索**：该网站不再出现在搜索结果中

收藏夹结果回车即可打开对应网址。

## 使用示例

**打开固定站点**

1. 新增网站，类型选「普通网页」，地址填 `https://mail.example.com`。
2. 在搜索框输入站点名称或别名，回车打开。

**用模板搜网页**

1. 新增网站，类型选「{query} 搜索网页」，地址填 `https://www.bing.com/search?q={query}`。
2. 在搜索框输入要搜的内容，选中「使用 xxx 搜索“…”」回车。
3. 若常用剪贴板关键词，可把查询来源设为「仅使用剪贴板」，或给该网站设热键。

**搜收藏夹**

1. 确认本机已安装 Edge、Chrome 或 Firefox，并在管理窗口看到对应 Profile。
2. 输入 `bookmark-web` 附着后，输入收藏夹标题中的关键词。

## 说明

- 当前版本不搜索浏览历史，只索引收藏夹。
- 收藏夹按标题匹配，不按网址搜索。
- 需要浏览器已在本机安装且存在可读的本地 Profile；便携版或不在默认路径的安装可能无法发现。
- 自定义网站与设置保存在 MioKit 中；卸载插件时按宿主的数据清理策略处理。
