# 内置网页与节点扩展

网站节点可以打开在线地址、带 `{query}` 的搜索模板或本地 HTML。默认仍使用外部浏览器；切换为“内置 ShadWindow”后可以配置运行环境、脚本与权限。

## 导航与窗口

内置窗口始终由网页铺满内容区域，不显示导航按钮、地址栏、常驻状态文字或日志。“调试工具”开关仅控制是否允许通过 F12 或网页右键菜单打开开发者工具。弹窗拦截提示与需要处理的错误仅在发生时显示。

每个节点保留一个主窗口。重复打开普通网页会激活主窗口；搜索模板的新查询在主窗口导航。

外部浏览器与内置窗口可以反复切换，切换不会清空内置窗口的目录、脚本、权限或浏览器数据。保存后仍打开的旧窗口会提示需要重新打开；再次从列表或搜索入口打开内置网页时，会关闭失效的主窗口与子窗口，等待资源释放后应用最新配置。

普通链接、表单和 HTTP 重定向沿用当前窗口。对于 `target="_blank"` 和 `window.open()`，可选择：

- 新建 ShadWindow，默认选项，保留 opener 与网页消息通信。
- 在当前窗口打开。
- 交给外部浏览器。
- 阻止新窗口。

无用户操作触发的弹窗默认被拦截，可以临时打开其地址，或为节点允许自动弹窗。对于已被拦截的登录弹窗，应允许后在原网页重新点击登录，以重新建立 opener 关系。

子窗口共享节点的浏览器 Environment、Profile 和配置。关闭主窗口不会关闭子窗口。删除节点、插件停止或“重新打开以应用”会关闭该节点的全部窗口。

跨到非可信来源时，默认继续浏览，但不注入服务和用户脚本；也可以配置为外部打开。外部打开模式不会转移内置浏览器的登录状态、POST 请求或弹窗通信。

## 数据目录与虚拟 host

外部浏览器使用自身的用户配置，不需要设置插件数据目录。保存外部打开的网站时，不解析或校验内置窗口专属的数据目录、映射、脚本和权限；已有设置会保留，切换为内置窗口时再校验。

每节点默认使用插件数据目录下的独立浏览器目录。可以指定独立的绝对路径，保存 Cookie、登录状态、localStorage 和 IndexedDB。修改目录不会迁移旧数据。不同节点不能使用重叠的数据目录。

网站切换为外部打开或修改数据目录后，尚未关闭的内置窗口仍占用原目录；关闭这些窗口前，其他网站不能复用该目录。

本地 HTML 默认将其所在目录映射为稳定的 HTTPS host，名称由节点 Id 派生。可以编辑 host，或关闭映射使用真实 `file://` 地址。更改 host 会改变浏览器存储所属的来源。

额外目录映射可配置启用状态、host、目录和访问策略：

| 策略 | 用途 |
| --- | --- |
| DenyCors | 默认；禁止跨来源脚本读取 |
| Deny | 禁止跨来源资源访问 |
| Allow | 显式允许跨来源访问，仅用于可公开的资源 |

映射提供静态资源读取，不提供文件写入，也不自动将映射来源设为可信。宿主保留的 `jsruntime.local`、`miokit.locale` 不可覆盖。

节点键值数据另存于节点 EAV 属性中，与浏览器缓存分开。删除网站节点不会自动删除磁盘上的浏览器目录或用户文件。

## 权限与可信来源

所有注入权限默认关闭。开启后，网页通过 `window.Mio` 调用相应服务。每次调用都在 C# 端检查节点、文档会话、来源及权限。

在线入口的精确来源默认可信。额外来源使用 `https://example.com` 或 `http://localhost:3000` 格式，不含路径或通配符。协议、主机、端口必须匹配。可信来源共享此节点的服务权限和键值数据。

本地 `file://` 页面按入口目录边界检查，不将所有本地文件视为可信。iframe 不注入服务或用户脚本。

文件读取、写入分别授权，同时需要授权目录范围。文件选择器随读写权限一并可用，可对当前窗口临时授权所选文件或目录。子窗口不继承其他窗口的临时选择授权。路径穿越、符号链接和目录联接不能绕过文件服务的目录授权。外部打开链接无需单独授权，仅限可信页面调用。

摄像头、麦克风、定位、网页通知、浏览器剪贴板读取和浏览器文件系统权限单独配置，默认拒绝。网页下载当前需要在外部浏览器进行。

保存权限等运行配置后，旧窗口拒绝后续注入服务请求，并以右上角浮层提示“重新打开窗口后生效”，不会挤压网页或改变其视口尺寸。编辑页顶栏也保留提示和“重新打开窗口”操作，离开后返回仍可看到待应用状态；重开失败会保留提示，成功后清除。“重新打开窗口”会关闭主窗口及子窗口，然后加载新配置。页面导航会使旧文档会话失效，旧请求的异步结果不会发往新页面。

## JavaScript API

所有方法返回 Promise。失败时抛出包含 `code` 和 `message` 的 Error。

```javascript
await Mio.ready;

// 节点专属 JSON 数据；需要 storage 权限
await Mio.storage.set('preferences', { theme: 'dark' });
const preferences = await Mio.storage.get('preferences');
const keys = await Mio.storage.keys();
await Mio.storage.remove('preferences');
await Mio.storage.clear();

// files.write；原生选择器临时授权所选文件
const target = await Mio.dialogs.saveFile('preferences.json');
if (target) await Mio.files.writeText(target, JSON.stringify(preferences));

// files.read
const source = await Mio.dialogs.openFile();
if (source) console.log(await Mio.files.readText(source));

// 参数 true 表示请求读写目录；仍需对应的 files 权限
const directory = await Mio.dialogs.openDirectory(true);

// 已授权路径下的其他文件操作
const entries = await Mio.files.list(directory);
const base64 = await Mio.files.readBase64(source);
await Mio.files.writeBase64(target, base64);
await Mio.files.createDirectory(directory + '/new-folder');
await Mio.files.move(source, target);
await Mio.files.delete(target); // 删除单个文件，不提供递归删目录

await Mio.clipboard.writeText('保存完成');
const text = await Mio.clipboard.readText();
await Mio.notifications.show('保存完成', '本地工作台');
await Mio.external.open('https://example.com');
```

| 错误码 | 含义 |
| --- | --- |
| document.expired | 文档已失效、来源不可信、节点已卸载或配置已更新 |
| permission.denied | 未开启相应能力 |
| path.invalid | 文件路径不是绝对路径 |
| path.denied | 路径不在授权范围或包含目录联接/符号链接 |
| service.invalid / operation.invalid | 未知服务或操作 |
| url.invalid | 外部打开地址不是 HTTP/HTTPS |
| operation.failed | 参数解析、文件系统或其他操作失败 |

键值数据通过宿主 EAV 写入及批处理机制持久化，API 成功表示逻辑修改已接受，不额外承诺强制同步落盘。

## 生命周期脚本与 Debug

支持文档创建、DOM 就绪、加载完成、窗口关闭前四个阶段。每阶段可配置多段脚本，按列表顺序执行；单段失败会记录错误并继续。脚本可直接使用 `await Mio.storage.set(...)` 等 API，但仍须获得对应权限。

刷新、完整导航及子窗口分别执行生命周期；SPA 路由与锚点变化不重复执行。WebView2 弹窗首次初始化可能从临时 `about:blank` 开始，此时等待实际来源确定后才尽早执行创建脚本，不提前授予空白页权限。

可信来源的弹窗会提前提供可等待的 `Mio` API，网页自己的早期脚本可使用 `await Mio.ready`。实际文档与宿主消息通道就绪后才开始调用服务；若弹窗转向非可信来源，则移除临时 API。

正常关闭前脚本最多等待两秒。插件停止、节点删除及重新打开等强制清理不等待脚本；异常退出也不保证执行。

Debug 默认关闭。开启后提供 WebView2 DevTools 及脚本错误日志，在 Release 构建中同样有效。

## 本地构建与测试

`MioKit.Sdk`、`MioKit.Extensions`、`MioKit.Webview2` 和 `MioKit.SourceGenerate` 统一引用已发布的 `1.3.1` NuGet 包，版本在 `Directory.Build.props` 中管理，无需宿主源码路径。

`MioKit.Webview2` 包已提供受保护的 `CreateEnvironmentAsync(userDataFolder, options)` 钩子，供子窗口复用 opener 的 Environment。插件最低 SDK 版本为 `1.3.1`；运行宿主也应提供相应 API。

```powershell
dotnet test tests/MioKit.WebSearch.Tests.csproj
dotnet build MioKit.WebSearch.slnx -c Release
```

后台测试使用内存 SDK Store 和模拟消息通道，不创建 UI/WebView 控制器，不连接用户数据库，也不读取浏览器配置。覆盖权限、节点存储并发、文件授权、配置兼容、来源校验和旧文档回包丢弃。常规浏览器构建及 SDK 的真实持久化管线仍由各自运行时负责。

Preview 工程及其浏览器测试入口已移除。当前测试命令与实际宿主验收范围见 [testing.md](testing.md)，历史验证记录见 [testing-history.md](testing-history.md)。
